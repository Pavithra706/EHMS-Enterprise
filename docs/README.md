# EHMS Documentation

Welcome to the Enterprise Hospital Management System documentation.

Documentation is organized by project phases.

## Phases

- Phase 00 – Project Initiation
- Phase 01 – Software Requirement Specification (SRS)
- Phase 02 – Business Workflows
- Phase 03 – System Architecture
- Phase 04 – Database Design
- Phase 05 – UI/UX Design
- Phase 06 – Development

Every phase contains all related documents, diagrams, and design decisions.

Documentation should always be updated before implementation.
