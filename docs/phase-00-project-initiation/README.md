# Phase 00 – Project Initiation

This phase establishes the foundation of the Enterprise Hospital Management System (EHMS).

## Deliverables

- Project Charter
- Project Vision
- Problem Statement
- Project Objectives
- Project Scope
- Stakeholders
- Hospital Study
- Department Analysis
- Technology Stack
- Development Methodology
- Coding Standards
- Git Workflow
- Risk Analysis
- Project Roadmap

Completion of this phase is mandatory before moving to the Software Requirement Specification (SRS).
