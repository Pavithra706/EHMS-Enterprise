# 1. Introduction

A stakeholder is any individual, department, organization, or system that influences, uses, manages, or is affected by the Enterprise Hospital Management System (EHMS).

Understanding stakeholder responsibilities ensures that the system satisfies clinical, administrative, financial, technical, and operational requirements.
