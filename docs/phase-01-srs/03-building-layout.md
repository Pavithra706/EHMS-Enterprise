# 1. Introduction

The Enterprise Hospital Management System (EHMS) is designed for a modern multi-storey super speciality hospital. The building layout ensures efficient movement of patients, doctors, nurses, visitors, emergency vehicles, medical supplies, and biomedical equipment while maintaining patient safety and operational efficiency.

---

# 2. Building Overview

The hospital consists of one integrated healthcare campus with multiple interconnected blocks.

```
                    SUPER SPECIALITY HOSPITAL

                     ┌───────────────────────┐
                     │   Administration      │
                     └──────────┬────────────┘
                                │
 ┌───────────────┐      ┌────────▼────────┐      ┌──────────────┐
 │ Emergency &   │──────│ Main Hospital   │──────│ Diagnostics  │
```

# 5. Building Connectivity

All blocks are connected through:

- Covered Walkways
- Dedicated Staff Corridors
- Patient Corridors
- Service Corridors
- High-Speed Elevators
- Emergency Elevators
- Wheelchair Ramps

Critical departments such as Emergency, ICU, OT, Radiology, and Blood Bank are located close to each other to reduce response time.
